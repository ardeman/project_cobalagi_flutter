# YouTube uploads

What to fill in when uploading the promo videos from `build/marketing/` (made by `tool/marketing/short_video.sh` and `promo_video.sh`; see README → Store listing → Promo videos). Keep every claim true for the released app, as in the store listing. Until the app is public on Google Play, the videos and descriptions say "Coming soon"; afterwards, re-render the short with `STORE=live` and change "Coming soon to Google Play" below to the store link.

YouTube can't replace a video's file: to update a video, delete it and upload the new one.

## Settings (all four videos)

| Setting | Choice | Why |
| --- | --- | --- |
| Thumbnail | Landscape: upload `thumbnail-<lang>.jpg` (needs a verified channel). Short: "Select from video", the first frame | The title card; the short's hook |
| Made for Kids | The channel owner's legal call. Recommended: No | The videos speak to parents ("Free · No ads", "Coming soon to Google Play"); YouTube may reclassify them because they show a children's game |
| Age restriction | No | |
| Paid promotion | No | Our own app |
| AI use | No | YouTube asks only about realistic content (a real person, place or event, or AI music as the main focus); the robot is animation, the music plays underneath, the narration imitates no real person |
| Automatic chapters, places, concepts | Off | Under a minute; no places |
| Tags | `Coba Lagi, cobalagi, coding for kids, learn to code, block coding, kids coding app, belajar coding anak` | Catches "cobalagi" written as one word |
| Video language | English for `-en`, Indonesian for `-id` | |
| Caption certification | This content has never aired on television in the US | |
| Licence | Standard YouTube licence; allow embedding (the Play listing embeds it) | |
| Shorts remixing | Allow video and audio | |
| Category | Education; Type, Problems, Academic system, Level and Exam left empty | A promo, not a lesson |
| Comments | On, anyone, top first; moderation Strict | A children's app: hold possibly inappropriate comments |
| Subtitles | Add → Upload file → With timing → `<video>.srt` | Many watch without sound |
| End screen, cards, quiz, files | None | An end screen would cover the end card |

The Google Play listing's **Video** field takes the landscape video's link; it must be Public or Unlisted, without ads and without an age restriction.

Coba Lagi helps children learn the basics of coding through play. They snap picture blocks together to guide a little robot across nine planets in space: steps in order, loops, their own magic block, checking the path ahead, fixing mistakes and more. No reading needed: every instruction is spoken, in Bahasa Indonesia and English.

• No accounts and no tracking: children's data stays on the device
